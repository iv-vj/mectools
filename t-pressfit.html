过盈配合压入力与温差装配

按厚壁圆筒（拉梅）公式算配合面压强、所需的压入力/压出力、可传递扭矩，以及温差法所需加热温度。

输入参数：配合直径 d、轮毂外径 d₂（空心轴时也指轮毂）、轴内径 d₁（实心轴填 0）、过盈量 δ（直径上的）、配合长度 L、轴材料弹性模量 E₁、轮毂材料弹性模量 E₂、轴泊松比 μ₁、轮毂泊松比 μ₂、配合面摩擦系数 f、轮毂线膨胀系数 α。参数可在页面内随时修改，结果实时更新。本页所有计算在浏览器本地完成，不联网、不上传数据。

配合面压强 p = 38.63 MPa；压入力 F = 116.49 kN（≈ 11.89 吨力）。
可传递扭矩 T = 5824.5 N·m（按摩擦传递，未计安全系数；联轴器等场合建议再除 1.5~2 的安全系数）。
温差法：使轮毂直径变化 50 μm 需温差 ΔT = 43.5 ℃，加上 20~40 ℃ 装配余量后建议加热到温升 73.5 ℃ 以上。
轮毂内表面环向应力 σt = 64.4 MPa，按最大剪应力理论的等效应力 σe = σt − σr = 103.0 MPa。低于常用钢材屈服强度，弹性范围内安全。

公式与取值说明

厚壁圆筒（拉梅）公式：配合面压强
  p = δ / [ d·( C₁/E₁ + C₂/E₂ ) ]
其中轴 C₁ = (d² + d₁²)/(d² − d₁²) − μ₁，实心轴 d₁ = 0 时退化为 C₁ = 1 − μ₁；轮毂 C₂ = (d₂² + d²)/(d₂² − d²) + μ₂。
压入力 F = π·d·L·p·f（把过盈面推合的轴向力，或压出时的分离力，两者大小相同）。
可传递扭矩 T = π·d²·L·p·f / 2。
温差法：加热轮毂（或冷却轴）使直径变化量等于过盈量，所需温差 ΔT = δ / (α·d)；实际装配温度还要在 ΔT 上加 20~40 ℃ 的装配余量。
注意：本页只算弹性范围。若算出的压强 p 使轮毂内表面等效应力超过材料屈服强度，则装配时会塑性变形甚至胀裂 —— 务必用下面的等效应力一行核对（按最大剪应力理论估算环向应力）。另外算出的压入力若大到不现实，说明该过盈用压装不可行，应改温差法或换配合。
