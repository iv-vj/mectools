压杆稳定校核（欧拉公式）

算柔度 λ 与临界柔度 λp，判断欧拉公式是否适用，并给出临界力、临界应力与稳定安全系数。

输入参数：长度系数 μ、杆长 L、弹性模量 E、最小惯性矩 I<sub>min</sub>、横截面积 A、材料的比例极限 σ<sub>p</sub>、实际工作压力 F、规定的稳定安全系数 [n]<sub>st</sub>。参数可在页面内随时修改，结果实时更新。本页所有计算在浏览器本地完成，不联网、不上传数据。

柔度 λ = 89.4 < λp = 100.8，属中/小柔度压杆，欧拉公式不适用（会明显高估临界力）。
请改用折减系数法：σ = F/A ≤ φ·[σ]，φ 按材料与 λ 查表（GB 50017 或材料力学教材附录）。本页仍列出欧拉公式的结果供参考，但不要用它做合格判定。
欧拉公式参考值：Fcr = 203.31 kN、σcr = 254.1 MPa —— 该值是偏大的乐观估计。

公式与取值说明

临界柔度 λp = π·√(E/σp)，σp 为材料的比例极限（Q235 取约 200 MPa，合金钢可更高）。
柔度 λ = μ·L / i，其中 i = √(Imin/A) 为截面最小惯性半径。
欧拉公式（仅当 λ ≥ λp 时适用）：Fcr = π²EImin / (μL)²，σcr = π²E / λ²。
为什么必须判 λ：λ < λp 时杆属于中柔度或小柔度压杆，欧拉公式会给出偏大的临界力，结果偏危险。工程上用折减系数法（φ 表）或经验公式处理，本页不覆盖那种情况，只会明确提示你。
I 要取截面最小惯性矩对应的方向 —— 压杆总是朝最弱的方向失稳。
稳定安全系数 [n]st 常取：钢材 1.8~3.0、铸铁 4.5~5.5、木 2.5~3.5。
