齿轮强度校核（接触 + 弯曲）

齿面接触应力 σH 与齿根弯曲应力 σF 校核。重合度系数与齿形系数均由齿数自动算出，也可切换为手动取值。

输入参数：小齿轮扭矩 T₁、模数 m、小齿轮齿数 z₁、大齿轮齿数 z₂、齿宽 b、载荷系数 K、弹性系数 Z<sub>E</sub>（钢-钢 189.8）、节点区域系数 Z<sub>H</sub>（标准直齿 2.5）、接触疲劳极限 σ<sub>Hlim</sub>、接触强度安全系数 S<sub>H</sub>、齿形系数取值方式、齿形系数 Y<sub>Fa</sub>（仅手动方式生效）、应力修正系数 Y<sub>Sa</sub>（仅手动方式生效）、弯曲疲劳极限 σ<sub>FE</sub>、弯曲强度安全系数 S<sub>F</sub>。参数可在页面内随时修改，结果实时更新。本页所有计算在浏览器本地完成，不联网、不上传数据。

齿面接触应力 σH = 881.4 MPa ≤ [σH] = 1200.0 MPa —— 接触强度合格，裕度 1.36 倍。
齿根弯曲应力 σF = 202.2 MPa ≤ [σF] = 428.6 MPa —— 弯曲强度合格，裕度 2.12 倍。
两项都满足时才合格。若要提高承载能力：当前按本组参数已合格，可反查下面的允许扭矩看还有多少余量。

公式与取值说明

接触强度 σH = ZE·ZH·Zε·√( 2K·T₁·(u+1) / (b·d₁²·u) )  ≤ [σH] = σHlim/SH
重合度系数 Zε = √( (4 − εα) / 3 )，Zε 与 εα 由本页按标准直齿轮几何自动求得。
弯曲强度 σF = 2K·T₁·YFa·YSa·Yε / (b·m²·z₁)  ≤ [σF] = σFE/SF
重合度系数 Yε = 0.25 + 0.75/εα
关于 YFa、YSa：本工具内置标准齿形系数表（z = 17…200 及 z→∞，α = 20°、齿根圆角 ρ = 0.38m），按 z₁ 线性插值自动取值，结果区会标出实际取用的数值。变位齿轮、内齿轮（表值 YFa ≈ YSa ≈ 2.65）或非标齿根圆角，请切到「手动输入」自行填值。z₁ < 17 时按表中 z = 17 取值并给出根切提示 —— 根切会削弱齿根、使真实 YFa 偏大，故本页 σF 偏乐观。
载荷系数 K = KA·Kv·Kβ·Kα，平稳载荷约 1.2~1.6，有冲击取 1.6~2.2。
